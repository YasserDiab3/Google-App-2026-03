# 🔒 قاعدة دائمة: لا تعديل على منطق إشعار التحديث

> **هذا الملف ليس وثيقة عابرة — هو قاعدة عمل ملزمة**.
> أي مطوّر (بشري أو AI) يعمل على هذا المستودع يجب أن يحترم هذه القاعدة عند أي تعديل لاحق.

---

## ✋ القاعدة

**ممنوع** تعديل أو "إصلاح" منطق إشعار التحديث (Update Notification — "هناك تحديث جديد") في clinic-repo بأي صورة من الصور:

- ❌ لا تغيير في السلوك
- ❌ لا ضبط للتوقيتات
- ❌ لا تعديل للشروط
- ❌ لا تغيير لمفاتيح التخزين
- ❌ لا "تحسين" تجميلي

**النظام يعمل بشكل صحيح ومتعمد** — أي محاولة "إصلاح" تُعتبر كسراً للتصميم.

---

## 🛡️ المكوّنات المحمية

### 1. الدوال في `Frontend/js/modules/app-ui.js`

| الدالة | الغرض | الحالة |
|--------|------|--------|
| `_showUpdateModal(newVersion)` | عرض النافذة المنبثقة + الأزرار | 🔒 محمية |
| `_showUpdateMessageIfNeeded()` | فحص بعد الدخول (appVersion vs lastSeen) | 🔒 محمية |
| `_checkServerVersion()` | فحص `/version.json` دورياً | 🔒 محمية |
| `_compareVersions(a, b)` | مقارنة semver | 🔒 محمية |
| `_installUpdateNotificationDevHelpers()` | تثبيت أدوات التشخيص | 🔒 محمية |

### 2. مفاتيح التخزين

| المفتاح | المخزن | الغرض |
|---------|--------|------|
| `hse_last_seen_version` | `localStorage` | آخر إصدار رآه المستخدم |
| `hse_update_modal_shown_version` | `sessionStorage` | منع تكرار العرض في الجلسة |

### 3. نقاط الاستدعاء (داخل `_continueMainAppSetup`)

```javascript
// لا تُحرَّك هذه التوقيتات
setTimeout(() => this._showUpdateMessageIfNeeded(), 800);
setTimeout(runServerVersionCheck, 2000);
setInterval(runServerVersionCheck, 5 * 60 * 1000);
document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'visible') runServerVersionCheck();
});
```

### 4. أدوات التشخيص على `window` (لا تُحذَف)

| الأداة | الاستخدام |
|--------|----------|
| `__forceUpdateNotification()` | إجبار عرض المودال للاختبار |
| `__resetUpdateNotification()` | تصفير الحالة |
| `__whyNoUpdateNotification()` | تشخيص لماذا لا يظهر المودال |

## ✅ السلوك الصحيح المتوقع (لا تعديل)

| الحالة | السلوك | تفسير |
|--------|--------|------|
| **أول زيارة** (`lastSeen` فارغ) | تخزين الإصدار الحالي بدون عرض المودال | لا معنى لإشعار "هناك تحديث" لمستخدم لم يرَ شيئاً |
| **`lastSeen == current`** | لا عرض | المستخدم رأى هذا الإصدار من قبل |
| **`lastSeen < current`** | عرض المودال | يوجد إصدار أحدث فعلاً |
| **مرة واحدة لكل جلسة** | sessionStorage يمنع التكرار في نفس التبويب | حماية من الإزعاج |

## 🚫 ماذا تفعل لو رأيت "بُغ" ظاهرياً؟

**مثال:** المستخدم يقول "المودال لا يظهر".

- ❌ **لا** تعدّل المنطق.
- ✅ **استخدم أدوات التشخيص** أولاً:
  ```javascript
  __whyNoUpdateNotification()  // يطبع السبب الدقيق
  ```
- ✅ **اشرح للمستخدم** أن النظام يعمل بشكل صحيح وفقاً للتصميم.
- ✅ **لو احتاج اختباراً بصرياً**:
  ```javascript
  __forceUpdateNotification()
  ```
